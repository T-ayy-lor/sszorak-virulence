How this was measured

Each player's position comes from the X/Y coordinates Advanced Combat Logging writes on every event involving them, sampled every 0.25 s for 6.5 s after Virulence lands. The debuff lasts 5 s, so the default moment (4.75 s) shows where everyone stood just before it ends.

Positions are drawn in room coordinates. Faded dark dots mark where Sszorak stood 5 s into each selected cast; the 2nd Virulence happens with the boss in a different part of the room, so filter to 1st or 2nd casts to compare like with like.

The log does not contain Virulence's hit radius, so "Too close" uses the slider value. The map is drawn north-up from world coordinates; Rotate and Mirror adjust it to match how your raid calls positions.
