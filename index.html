How this was measured

Tonight's data comes from an uploader script that reads the combat log and sends the Sszorak pulls after every pull or wipe. This page checks for new data every 30 seconds, and GitHub takes a minute or two to publish each upload.

Each player's position comes from the X/Y coordinates Advanced Combat Logging writes on every event involving them, sampled every 0.25 s for 6.5 s after Virulence lands. Virulence goes off 5 s after it lands, so the default moment (5.00 s) shows where everyone stood when it went off.

Positions are drawn in room coordinates. Faded dark dots mark where Sszorak stood 5 s into each selected cast; the 2nd Virulence happens with the boss in a different part of the room, so filter to 1st or 2nd casts to compare like with like.

The room image is from raidstrats.gg. The log has no coordinates for that image, so it was lined up by hand: Sszorak's spawn point (the same spot every pull) sits at the platform center, the data is turned 59° counter-clockwise from north-up so Sszorak's tank spot points at the platform edge he is pulled to, and the scale was set so the area the raid stood in meets the platform's rim. Treat wall positions as close, not exact.

Assigned spots come from the raid plan image, matched onto the same floor image so each ring sits where the plan draws it. For the 2nd Virulence the same layout is turned 180° around the room center, because Sszorak is pulled to the opposite side of the platform. Healers have no spot in the plan, so they have no ring.
